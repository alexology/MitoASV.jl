Settings and complexity

Settings

All settings are keyword arguments of assess_asvs and are recorded in results.parameters; see ?assess_asvs for the full list. The main ones:

SettingDefaultNote
genetic_code5NCBI table
frame, strandnothing, :+per gene in genes
terminal_stop_allowedtruefalse counts a final stop as internal (amplicons inside a gene)
hydrophobicity_window, window_threshold19, 1.6descriptive, not validity thresholds
cluster_method:connected_componentsor :hierarchical, :none (all ASVs form one group)
cluster_threshold0.03an example value, not a species boundary
cluster_level:nucleotideor :protein
min_group_size5unique sequences needed for comparative tests
radicalRadicalCriteria(grantham_min = 101)configurable, see ?RadicalCriteria
conservation_weightsnothing:henikoff or :abundance
anomaly_threshold3.5number or Dict gene ⇒ threshold
estimate_dndsfalseNG86 + Jukes–Cantor, only when estimable
comparative, concordance, clusteringtrueturn off expensive steps
length_tolerance, length_min_comparators0, 3allowed length difference (nt); other unique sequences needed to infer the expected length
species_colnothingcomparisons within species (recommended)
concordance_scope:species:all also compares across species (interspecific chimeras)
compare_gene_treesfalseUPGMA cophenetic comparison
threadedtrueresults do not depend on the number of threads

Computational complexity

n = distinct sequences, L = sequence length, m = members of a group.

StepTimeMemory
Parsing, translation, hydrophobicityO(n L), each distinct sequence onceO(n L)
Connected componentsO(n² L) worst case; the Hamming comparison stops as soon as the threshold is exceeded, and unequal lengths use a banded edit distance whose band starts narrowedges only, no matrix
Hierarchical clusteringO(n² L) distances + O(n²) nearest-neighbour chainn × n matrix (limited by max_hierarchical = 3000)
Comparative analysesO(m L) per group, with leave-one-out by count subtractionO(L) per group
Robust scoresO(m² log m) with leave-one-out (m ≤ 200), otherwise O(m log m)O(m)
ConcordanceO(n² L)four n × n Float32 matrices (limited by max_concordance_asvs = 3000)

Distances and per-sequence metrics use Julia threads. Results are written to fixed slots or merged in a fixed order, so they are identical for any number of threads (start Julia with -t auto). As a guide, 2,105 simulated 2.6 kb ND2–COI ASVs (1,798 distinct) took about 7 s with 4 threads (4 s without concordance) on a laptop.
