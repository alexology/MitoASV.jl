MitoASV.MitoASV — Module
MitoASV

Reference-free biological plausibility assessment of mitochondrial protein-coding amplicon sequence variants (ASVs).

Plausibility is not authenticity: the package reports interpretable scores, diagnostic flags and supporting statistics. It never decides that an ASV is genuine or artifactual, and without external references, read-level data or experimental evidence it cannot separate genuine variants from sequencing errors, NUMTs or chimeras.

MitoASV.assess_asvs — Function
assess_asvs(df; sequence_col = :sequence, id_col = nothing, gene = :gene,
            genes = nothing, frame = nothing, strand = :+, genetic_code = 5,
            abundance_col = nothing, sample_col = nothing, replicate_col = nothing,
            cluster_col = nothing, species_col = nothing, kwargs...) -> AssessmentResult

Reference-free biological plausibility assessment of protein-coding ASVs. The input DataFrame is not modified and no row is removed; every output table maps back to input rows through row.

Input

  • One column per gene (the usual input): genes = Dict(:ND2 => :nd2_seq, :COI => :coi_seq) maps each gene to the column holding its sequences (strings, BioSequences sequences or missing). Columns can also be given as (column = :nd2_seq, frame = 1, strand = :+). frame and strand passed as arguments apply to genes without their own. Without a full-sequence column, each gene is grouped on its own sequences, so a row missing one gene is still analysed for the others.
  • sequence_col: column with the whole amplicon, for single-gene analyses or when genes are given by coordinates. It is ignored if absent and every gene has a column.
  • id_col: optional ASV identifiers (default: the row number).
  • gene, frame, strand: single-gene analysis of the whole sequence.
  • genes with coordinates on sequence_col, e.g. Dict(:ND2 => (start = 1, stop = 900, frame = 1), :COI => (start = 1200, stop = 2700, frame = 1)). Coordinates are 1-based and inclusive; see GeneSpec.
  • Length: each gene's length is compared with the expected length, inferred as the modal length of the other unique sequences of that gene in the same species (or comparison group): length_tolerance = 0 nt, length_min_comparators = 3. See results.lengths.
  • genetic_code: NCBI table (default 5, invertebrate mitochondrial).
  • abundance_col: read counts; used for chimera parent abundance and, if requested, abundance weights. With sample_col, the same sequence may appear in several rows (long format): sequences are analysed once.
  • sample_col, replicate_col: reported as detection support (number of samples/replicates), never used as evidence of authenticity.
  • species_col: species of each ASV (for example a species column from a taxonomic classifier). When given, every comparison stays within a species: clustering is run separately in each species, so groups never mix species; with clustering = false each species is one group; with cluster_col the group is the (species, cluster) pair; the ND2–COI concordance compares ASVs of the same species (concordance_scope = :species; :all compares across species, needed to detect interspecific chimeras). A sequence assigned to two species is analysed in each separately. Rows with a missing species get no comparison group (:missing_species) and their comparative tests are not evaluated. The reading-frame consensus remains dataset-wide (it depends on the primers).
  • cluster_col: user-provided comparison groups (replaces clustering; combined with species_col when both are given).

Settings (keyword arguments, all recorded in results.parameters)

  • Frames: terminal_stop_allowed = true, frame_consensus_min = 0.75, frame_min_support = 3.
  • Hydrophobicity: hydrophobicity_window = 19, window_threshold = 1.6, hydrophobic_cutoff = 0.0.
  • Grouping: clustering = true, cluster_method = :connected_components (or :hierarchical, :none), cluster_threshold = 0.03, cluster_level = :nucleotide (or :protein), linkage = :average, align_unequal = true, cluster_on = nothing (a gene name to cluster all genes on that gene, or :per_gene; default: the full sequence if there is a sequence_col, otherwise each gene separately), max_hierarchical = 3000.
  • Comparative analyses: comparative = true, min_group_size = 5, radical = RadicalCriteria(), conservation_weights = nothing (:henikoff or :abundance), rare_threshold = 0.05, estimate_dnds = false.
  • Anomalies: anomaly_threshold = 3.5 (a number, or a Dict gene => threshold for gene-specific calibration), loo_dispersion_max = 200.
  • Concordance: concordance = true, concordance_genes = nothing (first two genes), concordance_k = 5, chimera_min_improvement = 0.005, concordance_scope = :species, pair_discordance_threshold = 0.5, max_concordance_asvs = 3000, max_discordant_pairs = 1000, compare_gene_trees = false.
  • threaded = true: use Julia threads (results do not depend on the number of threads).

Sequences and genes

MitoASV.GeneSpec — Type
GeneSpec(name; start = 1, stop = nothing, frame = nothing, strand = :+, column = nothing)

Location of one protein-coding gene.

  • start, stop: 1-based inclusive positions on the input sequence as given (forward orientation; alignment columns if the input is aligned). stop = nothing means "to the end of the sequence".
  • frame: 1, 2 or 3, the position of the first base of the first complete codon, counted from the 5' end of the oriented gene segment. nothing means unknown; the frame is then inferred from a dataset consensus (see assess_asvs) or left unresolved.
  • strand: :+ (as given) or :- (the gene is the reverse complement of the start:stop segment).
  • column: name of a column that already holds the extracted gene sequence. When set, start/stop refer to that column's sequences.

A NamedTuple with these fields is accepted wherever a GeneSpec is expected, e.g. (start = 1, stop = 900, frame = 1).

MitoASV.RadicalCriteria — Type
RadicalCriteria(; grantham_min = 101, blosum62_max = nothing,
                abs_delta_kd_min = nothing, combine = :any)

Definition of a radical amino acid substitution. Each criterion set to a number is evaluated; combine = :any calls a substitution radical when at least one criterion holds, :all when all hold.

The default (Grantham distance ≥ 101) follows the classes of Li, Wu & Luo (1984): conservative 0–50, moderately conservative 51–100, moderately radical 101–150, radical > 150. It is a convention, not a biological constant.

Hydrophobicity

MitoASV.hydrophobicity_metrics — Function
hydrophobicity_metrics(protein; window = 19, window_threshold = 1.6,
                       hydrophobic_cutoff = 0.0) -> NamedTuple

Kyte-Doolittle summary of one translated sequence. Residue statistics use the 20 standard residues only; n_residues_scored gives their number.

  • mean_kd, median_kd, sd_kd: residue hydropathy statistics.
  • frac_hydrophobic: fraction of residues with hydropathy > hydrophobic_cutoff.
  • n_windows, frac_windows_above: number of complete windows and the fraction whose mean exceeds window_threshold. The default 1.6 with a 19-residue window is the transmembrane-segment heuristic of Kyte & Doolittle (1982); it is descriptive, not a validity threshold.
  • max_window_kd, min_window_kd.
  • reason: why some values are missing ("" if none are).

MitoASV.hydrophobicity_profile — Function
hydrophobicity_profile(protein; window = 19) -> Vector{Union{Missing,Float64}}

Sliding-window mean Kyte-Doolittle hydropathy. Element k is the mean of residues k:(k + window - 1); windows that contain a residue without a hydropathy value (X, *, -, B, Z, ...) are missing, so stops and gaps are never averaged over. The result is empty when the protein is shorter than window.

Substitutions

MitoASV.compare_proteins — Function
compare_proteins(seq1, seq2; radical = RadicalCriteria(), min_identity = 0.5) -> NamedTuple

Compare two aligned protein sequences position by position.

Positions are compared only if both sequences have the same length (an alignment, or ungapped sequences known to be colinear, such as amplicons from the same primers read in the same frame). Sequences of different length raise an ArgumentError: align them first. Homology cannot be proven without a reference; when identity over compared positions is below min_identity, homology_warning is true and the metrics should not be interpreted as substitutions between homologous residues.

Position handling:

  • both standard residues: compared (n_compared); differing pairs are substitutions, scored with Grantham, BLOSUM62 and Kyte-Doolittle change (seq2 minus seq1);
  • a gap (-) against a residue: n_gap_positions; gap against gap is ignored;
  • a stop (*) against a standard residue: n_stop_differences;
  • X, B, Z, J, other symbols: n_uncomparable.

Returned metrics are missing when no substitution exists to summarise (for example grantham_mean with zero substitutions); counts are integers. substitutions lists each substitution.

Codons

MitoASV.codon_usage — Function
codon_usage(sequences; genetic_code = 5, frame = 1) -> DataFrame

Codon counts over all sequences (each sequence counted once; ambiguous and gap codons skipped) and relative synonymous codon usage (RSCU, Sharp & Li 1987): the observed count divided by the mean count of the synonymous codons. RSCU is missing for stop codons, single-codon amino acids and amino acids that were never observed.

source
MitoASV.compare_codons — Function
compare_codons(seq1, seq2; genetic_code = 5, frame = 1, dnds = false) -> NamedTuple

Codon-aware comparison of two aligned coding sequences (same length, same frame). Codons with ambiguous bases or gaps are skipped (n_codons_skipped).

Differences are counted at each codon position (diff_pos1..3). Synonymous and nonsynonymous differences follow Nei & Gojobori (1986): a codon differing at one position is classified directly; codons differing at two or three positions are averaged over all mutational pathways that avoid stop codons (fractional counts). Codon pairs involving a stop codon, or with no valid pathway, are counted in n_unclassified_codons and not classified. Differences at third positions are therefore not assumed synonymous.

With dnds = true, pN/pS, Jukes-Cantor dN/dS and their ratio are returned when estimable (≥ 30 codons, at least one synonymous difference, p < 0.75); otherwise missing with dnds_reason. dN/dS is never the raw ratio of difference counts.

Grouping

MitoASV.cluster_asvs — Function
cluster_asvs(sequences; method = :connected_components, threshold = 0.03,
             level = :nucleotide, linkage = :average, align_unequal = true,
             genetic_code = 5, frame = 1, threaded = true) -> DataFrame

Group sequences by pairwise distance without any reference.

  • method = :connected_components: single-linkage components of the graph with an edge for every distance ≤ threshold. Only edges are stored (no distance matrix). Components can chain relatively divergent sequences through intermediates.
  • method = :hierarchical: agglomerative clustering (linkage = :average, :complete or :single) cut at threshold; needs an n × n matrix. Distances above max(0.5, 2 × threshold) are stored at that cap.
  • level = :nucleotide: p-distance on equal-length sequences (pairwise deletion of gaps and ambiguous bases); unequal lengths use a banded edit distance (align_unequal = true) or are not linked.
  • level = :protein: p-distance between translations (genetic_code, frame), equal lengths only.

Identical sequences always share a cluster. missing sequences get a missing cluster. The 3% threshold is an example, not a universal species boundary. Returns index, cluster, cluster_size (number of input sequences in the cluster) and nn_distance (distance to the nearest other unique sequence if ≤ threshold, else missing).

Conservation

MitoASV.conservation_analysis — Function
conservation_analysis(sequences; weights = nothing, min_sequences = 5,
                      rare_threshold = 0.05, radical = RadicalCriteria()) -> NamedTuple

Conservation of aligned (equal-length) protein sequences estimated from the sequences themselves; missing entries are skipped.

  • weights = nothing: unweighted (each sequence counts once). Other options: :henikoff (position-based weights that down-weight redundant sequences), :unique (identical sequences collapsed to one), or a numeric vector (e.g. abundances; reads are not independent evolutionary observations, so interpret with care).
  • Positions need at least min_sequences - 1 informative residues in the leave-one-out set, and the analysis needs at least min_sequences sequences; otherwise values are missing and reason explains why.

Returns

  • positions: per position n_informative, consensus (missing on ties), consensus_freq, entropy (bits, 20 residues), conservation (1 − entropy / log2 20) and freq_A … freq_Y, using all sequences;
  • sequences: per sequence leave-one-out scores: substitutions against the leave-one-out consensus (Grantham, BLOSUM62, hydropathy change, radical changes), unseen and rare residues, conservation-weighted Grantham and hydropathy changes, and radical substitutions at sites invariant among the other sequences;
  • n_sequences, n_effective (Kish effective number from the weights), weights, reason.

Anomaly scores

MitoASV.robust_anomaly_scores — Function
robust_anomaly_scores(values; resolution = 0.0, loo = true, min_comparators = 4)
    -> NamedTuple of vectors

Robust anomaly scores (x - median) / dispersion for each value, computed against the other values (leave-one-out) when loo = true.

Dispersion, in order of preference:

  1. 1.4826 × MAD (consistent with the SD for normal data);
  2. if the MAD is zero, 1.2533 × mean absolute deviation (Iglewicz & Hoaglin 1993);
  3. never below resolution, the smallest meaningful change of the metric (for example one substitution). This prevents extreme scores caused only by zero dispersion.

If the dispersion is still zero, the score is 0 for a value equal to the median and missing otherwise (reason explains).

missing values, and values with fewer than min_comparators non-missing comparators, get missing scores with a reason.

Returns value, median, dispersion, dispersion_method, score, reliable, n_comparators, reason.

ND2–COI concordance

MitoASV.gene_concordance — Function
gene_concordance(seqs1, seqs2; k = 5, min_improvement = 0.005,
                 pair_threshold = 0.5, max_pairs = 1000, align_unequal = true,
                 proteins1 = nothing, proteins2 = nothing, abundance = nothing,
                 compare_trees = false, threaded = true) -> NamedTuple

Concordance between two genes of the same ASVs (seqs1[i] and seqs2[i] come from ASV i; sequences as strings or mask vectors). Returns per_asv (DataFrame), pairs (discordant pairs), global_spearman_nt, global_spearman_aa and tree_spearman.

Per ASV:

  • nn_gene1, nn_gene2: nearest neighbour in each gene (ties: lowest index);
  • knn_jaccard: overlap of the k nearest neighbours in the two genes;
  • row_spearman_nt (and _aa): rank correlation of the ASV's distances to all others in the two genes;
  • single_parent_distance: best length-weighted distance to one other ASV over both genes; two_parent_distance: the same allowing a different ASV for each gene; two_parent_improvement = single − two (≥ 0). A large improvement with two different parents is the pattern expected for a chimera between them (as in UCHIME);
  • parents_abundance_ratio: min(parent abundance) / ASV abundance, when abundances are given (chimeras are usually rarer than their parents).

Pairs are reported when the percentile ranks of their distances in the two genes differ by ≥ pair_threshold (at most max_pairs, most discordant first). Unequal-length sequences use a banded edit distance capped at 0.25; pairs beyond the cap are treated as not comparable.

Simulated data

MitoASV.simulate_asv_dataset — Function
simulate_asv_dataset(; seed = 1, nd2_codons = 330, coi_codons = 510, spacer = 120,
                     n_variants = 10) -> NamedTuple

Build a SIMULATED long-range ND2–spacer–COI amplicon dataset for examples and tests (random open reading frames under NCBI table 5; not real sequences). Returns data (a DataFrame with ASV, sequence (whole amplicon), species, category, lineage, abundance, sample, simulated = true, and one column per gene: ND2, COI), genes (coordinates on sequence), gene_columns ([:ND2 => :ND2, :COI => :COI], for assess_asvs(data; sequence_col = nothing, genes = gene_columns, frame = 1)) and description.

Species: Simulatus alpha holds lineages A and B (two deep intraspecific mitochondrial lineages) and categories 1–6; Simulatus beta (category 8) is an unrelated species. Categories:

  1. plausible_variant: lineage A variants with 1–3 synonymous changes;
  2. single_nonsynonymous: one conservative amino acid change in COI;
  3. radical_substitution: one radical change at a COI site invariant in A;
  4. internal_stop: a stop codon inside COI;
  5. frameshift: a 1-nt deletion inside COI;
  6. recombinant: ND2 (and spacer) from lineage A + COI from lineage B;
  7. divergent_plausible: lineage B, ~25 % of codons changed (≈ 8 % of nucleotides; synonymous third positions and a few conservative changes), with its own variants;
  8. other_species: variants of an independent random ORF pair, species Simulatus beta.
